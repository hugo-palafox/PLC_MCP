# Testing and Visualizing Grafana Dashboards

This guide shows you how to test and visualize the dashboards generated by `dashboard_generator.py`.

## Method 1: Quick HTML Preview (No Grafana Required) ⚡

**Fastest way to see your dashboard structure:**

```powershell
.venv\Scripts\python.exe preview_dashboard.py
```

This generates `dashboards/Testing_Machine_preview.html` which you can open in any browser.

**What you'll see:**
- Dashboard layout with all panels
- Panel types (Gauge, Stat, TimeSeries)
- Query expressions for each panel
- Grafana-like dark theme

## Method 2: Import into Grafana (Full Experience)

### Option A: Docker (Recommended)

1. **Start Grafana**:
```powershell
docker run -d -p 3000:3000 --name=grafana grafana/grafana
```

2. **Generate dashboard via AI**:
```powershell
.venv\Scripts\python.exe ollama_host.py
# Ask: "Generate a dashboard for Testing_Machine"
```

3. **Import**:
   - Open http://localhost:3000
   - Login: `admin` / `admin`
   - Click **+** → **Import dashboard**
   - Upload `dashboards/Testing_Machine_dashboard.json`

### Option B: Grafana Cloud (Free)

1. Sign up at https://grafana.com/auth/sign-up/create-user
2. Create a free cloud instance
3. Import the JSON file via the UI

## Method 3: JSON Validation

Verify the JSON structure is valid:

```powershell
.venv\Scripts\python.exe -m json.tool dashboards/Testing_Machine_dashboard.json
```

## What's in the Dashboard?

The generated dashboard includes:

1. **OEE Gauge** (6 columns wide)
   - Shows Overall Equipment Effectiveness
   - Query: `Global.fOEE_Overall`

2. **Total Produced Stat** (6 columns wide)
   - Total parts count
   - Query: `Global.nTotalPartsProduced`

3. **Good Parts Stat** (6 columns wide)
   - Good parts count
   - Query: `Global.nGoodPartsProduced`

4. **Production Rate Time Series** (24 columns wide)
   - Shows production rate over time
   - Query: `rate(Global.nTotalPartsProduced[5m])`

## Customizing Dashboards

Edit `dashboard_generator.py` to:
- Add more panels
- Change panel sizes (via `GridPos`)
- Modify queries
- Add thresholds and alerts

Then regenerate:
```powershell
.venv\Scripts\python.exe dashboard_generator.py
```
